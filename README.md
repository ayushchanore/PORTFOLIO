# Ayush Chanore — Portfolio

A personal portfolio website built with React.js and Tailwind CSS.

## Features

- Responsive design with dark mode support
- Resume viewer with email notification on open (via EmailJS)
- Projects showcase with live demo links
- Skills, Experience, and Contact sections

## Tech Stack

- React.js, Tailwind CSS, Framer Motion
- EmailJS (resume open notifications)
- Vite

## Getting Started

```bash
cd frontend
npm install
npm run dev
```
